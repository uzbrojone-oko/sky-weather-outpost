## Learning companion

- [Handbook](HANDBOOK.md) — intentionally written in Polish as an informal, human-friendly learning companion that explains the reasoning and mental models behind the project.

The Handbook is explanatory rather than normative. If it ever differs from the canonical project documentation, the canonical English documents are the source of truth.

An English Handbook may be added in the future if there is a real need for one, but maintaining a second translation is not a project requirement.
